UCM’s online catalogs are designed to help you quickly locate and save details about the University’s schools, degree programs, courses, campus information, and policies.

Here are some tips for using the catalog:

  • The left-hand navigation bar provides links to the sections of the catalog.
  • Use the anchor links at the top of most pages to “jump” to the content you seek.
  • The Course Descriptions filter is a great tool.  Enter criteria such as course prefixes, numbers, keywords or phrases to identify courses of interest.
  • The Catalog Search tool is also comprehensive.  Use “Advanced Search” and include or exclude appropriate result types.

Follow this Icon Legend to learn how to navigate the catalog pages.

Plan (print degree planner) - view a printer-friendly version of a desired program
Save (add to My Favorites) - save a course of program to an individualized catalog - Must create an account
Print (printer-friendly page) - access a printer friendly version of a selected page
Social Media (share catalog information) - share catalog information on Facebook or Twitter
Learn (help) - view additional information on searching the catalog
